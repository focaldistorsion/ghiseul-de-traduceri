# Ghișeul de Traduceri

Site static de prezentare, versiunea 0.4.7. Fișierele publicate se află în `dist/`.

Previzualizare locală: deschide `dist/index.html` sau rulează un server static în directorul `dist`.

Înainte de lansare, configurați datele de contact reale, un serviciu sigur pentru primirea documentelor și paginile legale. Butoanele de contact sunt dezactivate până la implementarea acestor funcții. Nu introduceți date demonstrative în canalele publice.

Publicarea pe GitHub Pages folosește workflow-ul `.github/workflows/pages.yml` și sursa GitHub Actions din setările Pages.
